This is a Visual Basic .NET WinForms GUI program that uses my 2to51CL-FF.exe program to convert stereo audio files to 5.1 surround sound files.

Build the program and put the Stereoto51.exe file along with my 2to51CL-FF.exe command line program with all of its required .dll files into the same installation folder on your computer.

Note: Gemini AI Studio was used to generate the GUI code based on the source code from my 2to51CL-FF project.
